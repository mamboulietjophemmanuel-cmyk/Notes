À propos de MyNotes

MyNotes est un carnet de notes léger développé avec Tauri, React et TypeScript. Conçu pour offrir une expérience fluide sans distraction, il vous permet d'organiser facilement vos idées, documents et éléments de travail.

✨ Fonctionnalités

🚀 Performances ultra-rapides grâce à l'architecture Tauri v2.

🎨 Interface moderne & épurée pour une concentration maximale.

📁 Gestion des documents et persistance locale des données.

💾 Léger sur la mémoire par rapport aux applications web classiques.

📥 Téléchargement

Pour installer l'application sur Windows :

Rendez-vous sur la page des Releases.

Téléchargez le dernier fichier d'installation : MyNotes_0.1.1_x64-setup.exe.

Lancez l'installateur et suivez les instructions.

🛠️ Développement local

Si vous souhaitez exécuter ou contribuer au projet en local :

# Installez les dépendances
npm install # ou bun install

# Lancez en mode développement
npx tauri dev


Pour compiler le projet et générer les exécutables :

npx tauri build
